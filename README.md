# 图片水印工具

纯前端的图片水印工具：把多行文本以平铺方式叠加到图片上，也可以把文本写入频域作为**肉眼不可见的盲水印**；支持批量处理。所有处理都在浏览器本地完成，图片不会上传到任何服务器。

**在线使用：** <https://www.illageraris.dpdns.org/watermark/>

## 功能特性

- **单图 / 批量**：单图实时预览，批量以缩略图网格管理，两种模式共享同一套参数
- **可见水印**：多行文本平铺，字号、字体、加粗、颜色、描边、透明度、旋转角度与间距均可调，可一键关闭
- **原始分辨率导出**：预览为等比缩放，导出保持原图尺寸；支持 PNG 与 JPEG（可调质量）
- **批量导出**：缩略图直接显示加水印后的效果，可单张移除、一键清空；多张可打包为 ZIP 下载
- **盲水印**：基于 DFT 频域嵌入，正常观看不可见；可上传带水印的图片提取文本验证，嵌入与提取均显示进度并可取消
- **本地记忆**：参数与深色/浅色主题自动保存在本机，刷新后保持
- **纯前端**：基于 Canvas API，无需联网、无需安装

## 使用方法

### 单图模式

1. 打开页面，默认进入「单图」，点击预览区或将图片拖入页面
2. 在右侧参数面板输入水印文本（支持多行），调整字体、颜色、透明度、角度与间距
3. 点击「下载图片」，文件以 `原文件名_watermark.png/jpg` 命名

### 批量模式

1. 切换到顶部「批量」，点击上传区或把多张图片拖入页面
2. 缩略图会按当前参数显示水印效果，可点右上角 `×` 移除单张
3. 点击「批量导出」按当前参数逐张处理；勾选「打包为 ZIP」可合并为一个压缩包下载

### 盲水印

- 在参数面板打开「嵌入盲水印」，填写文本并调整强度后导出（格式自动锁定为无损 PNG）
- 点击顶栏「提取盲水印」，选择含水印的图片，即可显示嵌入的文本
- 盲水印写在导出图的最终像素里，因此会同时包含可见水印（若开启）

## 参数说明

| 参数 | 说明 | 范围 |
| --- | --- | --- |
| 平铺水印 | 关闭后只导出原图；盲水印仍独立生效 | 开 / 关 |
| 水印文本 | 支持多行，每行独立绘制，不自动换行 | 任意文本 |
| 文本字体 | 微软雅黑、宋体、黑体、楷体、仿宋与若干西文字体 | 10 种 |
| 字体大小 | 滑块与数字输入同步 | 12–200 px |
| 加粗 | 粗体绘制 | 开 / 关 |
| 文本颜色 / 描边颜色 / 描边宽度 | 提高复杂背景上的可读性 | 描边 0–10 px |
| 透明度 | 水印整体不透明度 | 0.05–1 |
| 旋转角度 | 平铺图案整体倾斜 | −90°–90° |
| 水平 / 垂直间距 | 控制平铺密度 | 0–400 px |
| 图片格式 | PNG（无损）或 JPEG（可调质量） | — |
| JPEG 质量 | 仅在 JPEG 格式下可调 | 0.6–1 |
| 嵌入盲水印 | 启用后格式锁定 PNG | 开 / 关 |
| 盲水印文本 | 写入频域的不可见文本 | ≤64 字符且 UTF-8 ≤200 字节 |
| 嵌入强度 | 空间域波纹幅度下限（灰度级），越大越鲁棒但越可能被察觉 | 0.5–10（默认 1.5） |

## 盲水印的边界

盲水印把文本编码为频域信号，因此有明确的适用条件：

- **尺寸**：图片任一边需不小于 256 像素，否则无法嵌入，也无法提取
- **不要重复嵌入**：同一张图重复写入会破坏原有信号
- **鲁棒性**：可抵抗平移、裁剪（保留 ≥256×256 区域）、90° 旋转与轻度缩放/压缩；对任意角度旋转、强有损压缩以及大段规则纹理的图片，可能无法提取
- **强度**：建议 1.5–3；强度越高越鲁棒，但波纹也可能被看见
- **无损导出**：PNG 是无损格式，JPEG 压缩会破坏频域信号，因此盲水印开启时格式固定为 PNG

## 浏览器兼容性

支持 Chrome、Edge、Firefox、Safari 等现代浏览器。中文字体依赖操作系统已安装的对应字体；未安装时会回退到系统默认字体。

## 隐私

所有图片都在你的浏览器内存中处理，不会上传、缓存到服务器或发送到任何第三方；页面本身不包含统计脚本。
