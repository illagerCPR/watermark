# 图片水印工具

一个纯前端的图片水印工具，可将多行文本以平铺方式叠加到图片上作为水印，并支持 DFT 频域盲水印与批量处理。零依赖、无需安装、无需联网，所有处理均在浏览器本地完成，图片不会上传到任何服务器。

## 快速开始

- 双击 `index.html` 即可在浏览器中打开使用，无需任何构建或安装步骤。
- 通过 GitHub Pages 直接使用：https://illagercpr.github.io/watermark/

## 功能特性

- **双 Tab 视图**：单图模式实时预览，批量模式多图缩略图管理，参数面板共享
- **图片上传**：点击选择或拖拽上传，支持 JPG / PNG / WebP
- **实时预览**：调整参数后约 80ms 内自动重绘
- **平铺水印开关**：可一键关闭可见水印，仅导出原图或仅嵌盲水印
- **批量处理**：多图上传后以缩略图网格预览，支持单张移除，一键按当前参数批量导出
- **原始分辨率导出**：预览为等比缩放，导出保持原图尺寸
- **DFT 盲水印**：将不可见文本嵌入频域，可重新提取验证；抗平移、裁剪与压缩，对旋转/缩放具备一定鲁棒性
- **本地处理**：基于 Canvas API，数据不离开本机

## 使用方法

### 单图模式

1. 打开 `index.html`，默认进入「单图」Tab，点击预览区或将图片拖入页面
2. 在右侧面板输入水印文本（可多行）并调整各项参数
3. 预览满意后点击预览区下方的「下载图片」，导出文件自动以 `原文件名_watermark.扩展名` 命名

### 批量模式

1. 点击顶部「批量」Tab 切换到批量视图
2. 点击上传区或拖拽多张图片到批量区，已选图片以缩略图网格显示
3. 鼠标悬停缩略图可点击 `×` 移除单张
4. 点击「批量导出」，按当前参数（含平铺水印与盲水印设置）串行处理所有图片并逐张下载，按钮文字显示进度

### 盲水印

- 勾选右侧面板「盲水印」开关，输入标识文本并调整强度
- 启用后导出格式自动锁定为 PNG；单图或批量导出均会嵌入盲水印
- 盲水印要求图片任一边均不小于 256 像素，过小的图片将在嵌入与提取时被拒绝处理
- 点击顶栏「提取盲水印」选择含水印 PNG，弹窗即显示嵌入的文本
- 盲水印可抵抗**任意平移、裁剪（保留 ≥256² 区域）、90° 旋转与轻度缩放/压缩**；对任意角度旋转与强有损压缩的鲁棒性有限（内容方向性强时可能失败）；同一张图请勿重复嵌入

## 实现原理

1. 将上传图片绘制到与原始分辨率一致的主 Canvas（若关闭「平铺水印」开关则止步于此）
2. 在离屏 Canvas 中绘制单个水印单元（多行文本 + 间距），测量最宽行确定单元尺寸
3. 通过 `createPattern` 将水印单元作为平铺图案
4. 主画布以图片中心为原点旋转指定角度，填充边长为图片对角线 2 倍的矩形区域，保证任意角度下水印无缝覆盖全图
5. 通过 `canvas.toBlob` 按所选格式与质量导出下载

### 盲水印实现

1. 导出时在空频谱上生成一个 256×256 的 delta 瓦片：同步模板（半径 0.05N 处 4 峰星座 + 共轭镜像）与文本比特的幅度差分对（成对随机频点，一峰一空）经单次 2D IFFT 得到空间瓦片，再按 256 周期平铺叠加到亮度通道
2. 文本编码为比特序列（魔数 + 长度 + payload + CRC8），位置由固定种子的伪随机生成器在频谱中频环带内选取；嵌入幅度 α 按目标强度经 Parseval 反解，并按内容自适应提升以保证强内容图可提取
3. 平铺结构使任意 256² 提取窗恰好包含一个循环位移的水印周期，幅度谱平移不变，因此天然抗平移与裁剪
4. 提取端对滑窗网格逐块 FFT：先用差分模板匹配估计缩放/角度候选解码，失败则改用径向能量直方图估计旋转角、沿半径估计缩放，在频域按校正坐标直接采样解码；成对频点幅度差分表决还原比特，魔数软门控 + CRC8 硬裁决，两块一致采信
5. 为保证 file:// 协议下可用，DFT 按行/列分片异步执行（不用 Web Worker），配合进度回调避免页面假死

## 文件结构

```
watermark/
├── index.html   # 页面结构：Tab 视图 + 参数面板 + 提取浮层
├── style.css    # 深色工具风格样式，支持窄屏自适应
├── script.js    # 可见水印逻辑：上传 / 平铺渲染 / Tab 切换 / 批量处理 / 导出
├── favicon.ico  # 网站图标
├── blind.js     # DFT 频域盲水印：嵌入 / 提取（零依赖，纯 JS FFT）
└── README.md
```
