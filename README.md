# 图片平铺水印制作工具

一个纯前端的图片水印工具，可将多行文本以平铺方式叠加到图片上作为水印。零依赖、无需安装、无需联网，所有处理均在浏览器本地完成，图片不会上传到任何服务器。

## 快速开始

双击 `index.html` 即可在浏览器中打开使用，无需任何构建或安装步骤。

## 功能特性

- **图片上传**：点击选择或拖拽上传，支持 JPG / PNG / WebP
- **实时预览**：调整参数后约 80ms 内自动重绘
- **原始分辨率导出**：预览为等比缩放，导出保持原图尺寸
- **本地处理**：基于 Canvas API，数据不离开本机

### 可调参数

| 参数 | 说明 | 范围 |
|------|------|------|
| 水印文本 | 支持多行，每行独立绘制 | 任意文本 |
| 文本字体 | 微软雅黑、宋体、黑体、楷体、仿宋、Arial 等 10 种 | — |
| 字体大小 | 滑块与数字输入双向同步 | 12–200 px |
| 加粗 | 开关 | — |
| 文本颜色 | 取色器 | 任意颜色 |
| 描边颜色 / 宽度 | 提高水印在复杂背景上的可读性 | 0–10 px |
| 透明度 | 水印整体不透明度 | 0.05–1 |
| 旋转角度 | 水印整体倾斜角度 | -90°–90° |
| 水平 / 垂直间距 | 控制平铺密度 | 0–400 px |
| 导出格式 / 质量 | PNG（无损）或 JPEG（可调质量） | 0.6–1.0 |

## 使用方法

1. 打开 `index.html`，点击预览区或将图片拖入页面
2. 在右侧面板输入水印文本（可多行）并调整各项参数
3. 预览满意后点击右上角「下载图片」，导出文件自动以 `原文件名_watermark.扩展名` 命名

## 实现原理

1. 将上传图片绘制到与原始分辨率一致的主 Canvas
2. 在离屏 Canvas 中绘制单个水印单元（多行文本 + 间距），测量最宽行确定单元尺寸
3. 通过 `createPattern` 将水印单元作为平铺图案
4. 主画布以图片中心为原点旋转指定角度，填充边长为图片对角线 2 倍的矩形区域，保证任意角度下水印无缝覆盖全图
5. 通过 `canvas.toBlob` 按所选格式与质量导出下载

## 浏览器兼容性

支持所有现代浏览器（Chrome、Edge、Firefox、Safari 最新版本）。字体选项中的中文字体（微软雅黑、宋体等）依赖操作系统已安装的字体。
